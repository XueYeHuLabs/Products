# Dogdou 常见问题

## 音频复用是什么？

在 Windows 消费者版本中，音频设备通常只能被一个会话独占使用。音频复用功能的作用，是让多个会话可以复用同一套音频设备。

建议在开启新会话前先执行一次音频复用，并在需要恢复默认占用关系时使用恢复音频相关操作。

## 启动时打开 Shell 是什么意思？

勾选该选项后，系统会在会话启动时自动启动默认 Shell 程序，通常是 `explorer.exe`。这种模式下的使用体验与普通桌面环境基本一致。

不勾选该选项时，会话启动后不会自动加载 Shell，因此你会进入一个没有桌面的运行环境。此时可以通过“创建进程”的方式手动启动需要的程序。

这种方式资源占用更低，更适合不需要完整桌面界面的场景。

## 创建进程功能是做什么的？

创建进程功能会在所选会话中启动指定程序，默认命令通常为 `cmd.exe`，也可以改为其他可执行程序，并附带启动参数。

补充说明：

- 命令行路径可以使用环境变量，例如 `%windir%\system32\cmd.exe`
- 当命令行路径中包含空格时，需要使用引号括起来，例如 `"%windir%\system32\cmd.exe"`

## 会话数量或进程数量有限制吗？

当前会话数量没有硬性限制，但创建过多会话可能导致系统资源紧张。

每个会话内的进程数量同样没有硬性限制，但进程过多也可能导致该会话的资源压力升高。

此外，会话内创建的进程可以访问系统资源，但是否能成功访问，仍然取决于当前用户权限以及系统安全策略。
