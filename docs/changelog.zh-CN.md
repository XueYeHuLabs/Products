# Dogdou 变更日志

[返回 README](../README.md) | [English Changelog](./changelog.en.md)

本文档基于历史版本记录整理，按版本汇总 Dogdou 的功能更新、修复与优化。

## v0.9.0.3

### 新功能

- 新增会话时区设置功能，允许用户为每个会话指定不同的时区。

### Bug 修复

- 修复跨会话剪贴板在长数据时不进行共享的问题。
- 修复开始菜单在某些情况下无法正确显示的问题。

### 优化

- 优化会话用户登录流程，提升登录体验。

## v0.9.0.2

### 新功能

- 新增跨会话剪贴板共享功能。

### Bug 修复

- 无。

### 优化

- 优化创建会话流程。
- 优化音频控制。

## v0.9.0.1

### 新功能

- 新增基于 WebView2 的界面，提升整体使用体验。
- 新增 LocalLinker 组件，并将其合并到 DogdouToolkit 中，提供更完整的能力。

### Bug 修复

- 修复应用可能随机崩溃的问题。

### 优化

- 改进用户体验。
