# Dogdou Changelog

[Back to README](../README.md) | [中文变更日志](./changelog.zh-CN.md)

This page summarizes Dogdou release notes by version, based on the original project changelog.

## v0.9.0.3

### New Features

- Added session time zone settings, allowing users to specify a different time zone for each session.

### Bug Fixes

- Fixed an issue where cross-session clipboard sharing would not work with long data.
- Fixed an issue where the Start menu might not display correctly in some cases.

### Optimizations

- Optimized the session user sign-in flow for a smoother login experience.

## v0.9.0.2

### New Features

- Added cross-session clipboard sharing.

### Bug Fixes

- None.

### Optimizations

- Optimized the session creation flow.
- Optimized audio controls.

## v0.9.0.1

### New Features

- Added a new WebView2-based UI for a better overall experience.
- Added the LocalLinker component and merged it into DogdouToolkit with expanded capabilities.

### Bug Fixes

- Fixed an issue that could cause the application to crash randomly.

### Optimizations

- Improved the overall user experience.
